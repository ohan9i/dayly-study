# 휴지통과 테마의 길게 누르기

[React Bits HoldButton](https://www.reactbits.dev/micro/hold-button)을 휴지통 아이콘과 상단·플래너 시계·설정의 테마 버튼에 연결했다. 원본 라이선스는 `docs/licenses/ReactBits-LICENSE.md`, 컴포넌트는 `src/HoldButton.tsx`에 있다.

- 2초 누르면 실행한다. 오른쪽으로 보라색(`#5227FF`) 채우기, 물결 6px, 빛 효과, 누름 배율 0.97, 모서리 14px를 적용했다. 중간에 놓으면 200ms 동안 채우기가 되돌아가고 완료 표시는 1.2초 뒤 초기화한다.
- 계획·업로드 미완료 파일의 휴지통은 길게 누른 후 기존 삭제 확인을 연다. 누름 완료를 실제 서버 삭제 성공으로 표시하지 않는다. 삭제 확인 취소와 계획·기록·첨부의 복구 보호는 그대로 유지된다.
- 테마 버튼은 길게 누르면 전환한다. 현재 선택된 테마는 실행되지 않으며, 기존 테마 저장·탭 동기화·전환 애니메이션을 유지한다.
- 버튼 밖으로 이동, 손 떼기, 포인터 취소, Escape, 포커스 이탈, 스크롤, 창 크기 변경, 백그라운드 전환 시 진행 중인 누름을 취소한다. 비활성화·숨김·언마운트 뒤 실행되지 않게 한다. 상단 토글은 외부 테마 변경 시 누름 상태를 새로 만든다.
- Enter/Space를 길게 눌러 사용할 수 있다. 화면 읽기 도구·스위치 제어의 가상 클릭도 활성화 경로를 제공하며, 휴지통의 최종 확인은 유지한다. 한국어 누름 안내와 완료 알림을 제공한다.
- 동작 줄이기에서도 실행 대기 2초는 유지한다. 물결·확대·펄스를 줄이고, 키보드 입력에서는 움직임을 생략한다. 프레임별 값은 DOM 참조에만 쓰며 누름·복귀가 끝나면 프레임 요청이 중단된다.

검증: 단위 테스트, 빌드, `tests/e2e/hold-button.spec.ts`, 기존 테마·진입·삭제 복구·공유·첨부·모바일 배치 테스트.
