# 계획 화면의 종이 전환

- 나의 하루에서 날짜를 변경하거나 달력·학습 흐름·설정으로 이동하면, 현재 보이는 계획 종이가 구겨지면서 다음 화면을 드러낸다.
- [React Bits PaperCrumple](https://www.reactbits.dev/micro/paper-crumple)의 실제 3D 종이 시뮬레이션을 사용한다. 원본 소스와 수정 사항은 `src/PaperCrumple.tsx`, 라이선스는 `docs/licenses/ReactBits-LICENSE.md`에 있다.
- 구김 강도 0.85, 구김 시간 0.55초, 접힘 6개, 날카로움 0.6, 주름 깊이 0.65, 종이 질감 0.08을 적용했다. 기존 드래그 API는 보존하며, 화면 전환에서는 자동 재생으로 연결했다. 입력과 체크 조작을 방해하지 않도록 전환 종이는 포인터를 받지 않는다.
- 실제 계획 DOM을 브라우저 안에서만 이미지로 변환한다. 화면 아래의 행을 제외하고 보이는 영역을 최대 2배 해상도로 생성하며, 캡처 이미지는 서버에 전송하거나 저장하지 않는다. 스크롤 위치를 유지하기 위해 앞쪽 행은 복제 레이아웃에 보존한다. SVG 진행률과 체크 아이콘의 스타일도 복제한다.
- 계획 화면은 메뉴 이동 중에도 마운트를 유지해 작성 중인 수행 기록과 선택한 파일이 남는다. 날짜 변경은 기존 동작대로 해당 날짜의 목록을 표시한다.
- 효과가 끝나면 장면·텍스처·WebGL 컨텍스트를 해제한다. 3D 코드는 별도 청크로 지연 로드한다.
- 동작 줄이기, 키보드 이동, 화면 밖의 종이, 캡처 실패, WebGL 미지원에서는 바로 이동한다. 캡처 대기는 최대 240ms로 제한한다. 연속 클릭에서는 마지막 선택을 우선하며, 스크롤·크기 변경·백그라운드 전환 때 효과를 정리한다.

검증: `npm test`, `npm run build`, `tests/e2e/paper-transition.spec.ts` 및 기존 첫 화면·플래너·테마·레이아웃 회귀 테스트.
