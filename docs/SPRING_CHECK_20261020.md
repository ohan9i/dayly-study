# 계획 완료 체크의 스프링 애니메이션

[React Bits SpringCheck](https://www.reactbits.dev/micro/spring-check)를 기본 목록의 할 일·세부 항목과 상세 편집창의 체크박스에 적용했다. 원본 라이선스는 `docs/licenses/ReactBits-LICENSE.md`, 수정한 컴포넌트는 `src/SpringCheck.tsx`에 있다.

- 흰색 채움과 어두운 체크 표시, 주 항목 28px·반경 9px, bounce 0.2, strikeLag 0.12, 왼쪽부터 나타나는 취소선을 사용한다. 세부 항목과 편집창의 체크 크기는 정보 위계에 맞춰 줄였다. 낮·밤의 기존 글자색을 유지하고 완료 글씨는 가독성을 위해 불투명도 0.72로 설정했다.
- 하나의 스프링 값이 채움 크기·체크 경로·박스 탄성·글씨 밝기·취소선 진행을 함께 제어한다. 프레임별 값은 DOM 참조에 직접 반영하며 React 상태를 프레임마다 갱신하지 않는다.
- 제목 버튼은 상세 화면을 열고, 체크박스는 완료 상태만 바꾼다. 기록 버튼과 상세 편집 입력도 별도 조작으로 유지한다. 여러 줄 문장은 각 줄에 취소선을 그리며, 장식용 텍스트는 DOM·접근성 이름에 중복되지 않는다.
- 실제 `checked`는 기존 플래너 상태에서 전달한다. 저장·완료 집계·공유 동기화·권한·오류 복구 로직은 그대로 사용하며, 저장 실패 시 시각 상태도 되돌아간다.
- 키보드와 동작 줄이기에서는 즉시 상태를 표시한다. 실행 중 설정 변경도 반영하며, 숨겨진 화면에서는 애니메이션을 생략한다. 편집창에서 체크해도 작성 중 글과 입력 포커스가 유지된다.
- 모바일 터치 영역은 44px로 유지하고 420px 이하에서는 기록 버튼을 세부 문장 아래로 배치한다. 종이 전환 캡처에도 새 취소선의 클리핑을 반영한다.
- 기존 HoldButton의 완료 안내는 빈 status 역할 대신 명시적 live region으로 제공해, 체크 저장 오류 안내와 구분한다.

검증: 단위 테스트, 빌드, `tests/e2e/spring-check.spec.ts`, 기존 체크 안정성·세부 항목 편집·진행률·실패 복구·공유·레이아웃 회귀 테스트.
