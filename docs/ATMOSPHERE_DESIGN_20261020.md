# Dayly 공부 공간의 분위기 — 2026-10-20

Soda 레퍼런스의 유리 질감·공간감·색상 전환을 기존 React 플래너에 적용했습니다. GPT-6 Astra의 읽기 전용 디자인·구현 검토와 [Emil Kowalski의 스킬](https://github.com/emilkowalski/skills)을 함께 사용했습니다.

## 화면과 동작

- 기본값은 기존 창가·바다 이미지의 `아침 창가`입니다. `밤 공부`에서는 남색 조명과 회청색 카드, 밝은 본문을 사용합니다.
- 모든 화면의 상단 해·달 버튼, PC 홈의 시계 아래 선택 버튼, 설정의 `공부 공간의 분위기`에서 전환할 수 있습니다.
- 선택은 `dayly.atmosphere`라는 독립된 브라우저 저장 값입니다. 계정·학습 데이터·백업 데이터와 별도로 관리하며, 저장 권한이 없어도 현재 화면의 전환은 동작합니다.
- HTML 진입 시 선택을 먼저 복원해 밤 테마를 다시 열 때 밝은 화면이 먼저 나타나는 현상을 줄입니다. 같은 사이트의 다른 탭에서 선택을 바꾸면 열린 화면에도 반영합니다. 모달이나 작성 중인 초안은 다시 만들지 않습니다.
- 오른쪽 시계에는 작은 SVG 책·스탠드를 추가했습니다. 장식만 마우스에 최대 가로 3px·세로 2px 반응합니다. 반복 렌더링이나 상시 애니메이션 루프를 추가하지 않았습니다.
- 글자·읽기 표면·배경 기본 조명은 동시에 바뀌며, 주변 빛과 스탠드 조명만 650ms 동안 전환합니다. 테마 전환 도중 글자가 배경과 같은 밝기가 되는 문제를 피하기 위한 결정입니다.
- 오늘의 마지막 항목 완료 시 작은 별이 900ms 이내에 사라집니다. 초기 조회·날짜/공간 변경·전체 수 변경만으로는 실행하지 않습니다.
- 1000px 이하에서는 장식과 시계 아래 선택 버튼을 숨기고 시계·날짜·문구를 간단한 행으로 표시합니다. 상단 버튼과 설정에서 테마를 변경할 수 있습니다.

## 표면과 색상

`src/styles.css`에 입력·초점·비활성·선택·hover·팝업·오류·모바일 메뉴의 공통 표면 변수를 추출했습니다. 밤 테마에서는 이 변수들을 함께 바꿉니다. 링크에 사용하는 밝은 강조색과 흰 글자가 올라가는 진한 버튼 배경을 `--sky-600`, `--accent-solid` / `--on-accent`로 분리했습니다. 완료 체크와 오늘 날짜에도 같은 구분을 적용합니다.

본문 카드의 불투명도는 아침 약 0.86→0.78, 밤 약 0.95→0.92입니다. 상단의 얇은 반사와 약한 그림자로 유리 질감을 표현하며, 목록과 입력 영역에는 포인터 이동이나 기울기를 적용하지 않습니다. blur 미지원 환경에는 테마에 맞는 불투명 표면을 제공합니다.

## 스킬 검토와 반영

적용한 스킬은 `emil-design-eng`, `review-animations`, `animation-performance`입니다. 실제 장치의 프레임 속도를 측정했다는 의미는 아니며, 아래는 코드 검토와 브라우저 동작 확인에 해당합니다.

| Before                                               | After                                                          | Why                                                    |
| ---------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------ |
| 장식 부모의 CSS 변수를 포인터마다 변경               | SVG 자신의 `style.transform`만 변경                            | 자식 전체의 스타일 재계산과 React 프레임별 렌더링 방지 |
| 밤 글자색이 먼저 바뀌고 풍경은 늦게 전환             | 읽기 대비는 즉시 교체, 장식 광원만 opacity 전환                | 전환 도중 제목·날짜의 대비 유지                        |
| 밤 시계 선택자의 우선순위가 모바일·fallback보다 높음 | `--moment-bg` 토큰을 동일 선택자에서 소비                      | 모바일 및 blur 미지원 표면이 정상 적용되도록 수정      |
| 눌림 축소가 키보드에도 적용될 가능성                 | 포인터 입력에만 축소, 키보드·reduced-motion에서 transform 제거 | 키보드와 움직임 줄이기 설정을 존중                     |
| 아침 시계 아래 문구에 보조 글자색 사용               | 더 진한 본문색 사용                                            | 배경과 합성했을 때 기준보다 낮았던 대비 보완           |

새 테마 버튼의 눌림 반응은 160ms, 장식 이동은 200ms이며 CSS transition으로 중간에 다시 입력해도 현재 위치에서 이어집니다. 마우스 hover는 fine pointer 조건으로 제한합니다. 키보드 입력에서는 움직임을 즉시 억제하고, `prefers-reduced-motion`에서는 기존 앱의 움직임 줄이기 규칙과 새 장식 제한을 함께 적용합니다.

## 검증

시각 검증 캡처와 대비 표본은 Git에서 제외된 `.local/atmosphere/`, 기존 사용성 검사는 `.local/usability/`에 저장합니다. 브라우저 검사는 Chromium과 테스트용 Supabase 응답을 사용합니다.

- 데이터·날짜·권한·암호화 백업 단위/SQL 검사: 72개 통과.
- TypeScript 및 production 빌드 성공.
- 브라우저 60개 시나리오 검증: 전체 실행에서 59개 통과 후 320px 대비 측정에서 로그인 토스트가 문구를 가리는 문제를 확인했습니다. 토스트 종료를 기다리도록 검사를 보완하고, 아침의 작은 테마 버튼 글자도 진하게 맞춘 최종 빌드에서 관련 8개 시나리오를 재실행해 모두 통과했습니다.
- 기존 로그인·공유 체크·권한·첨부·기록·복제·진행률·초안 유지 시나리오와 새 테마 복원·탭 동기화·저장 차단 대응·키보드·reduced-motion 검사를 포함합니다.
- 새 화면: 1366×768, 1920×1080, 320×800. 기존 사용성 검사: 1366×768, 1920×1080, 360×800. 기존 반응형 시나리오도 320~1536px 범위에서 통과했습니다.
- 아침 본문 대비 표본 최솟값은 약 4.68:1, 밤 홈·계정·상세의 표본은 8:1 이상이었습니다. 작은 테마 버튼·문구는 아침 표본에서 약 7.66:1 이상입니다. 이는 지정한 요소의 실제 합성 배경 표본 측정 결과입니다.
- Astra 최종 코드 검토: Approve. Prettier 검사 및 `git diff --check` 통과.

운영 Supabase의 스키마·권한 정책·저장 함수는 변경하지 않았습니다.
