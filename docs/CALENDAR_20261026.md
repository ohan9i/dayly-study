# 달력 개편 (2026-10-26)

날짜 칸에서 글자와 막대를 빼고, 모양 하나로 그날을 보여 주는 달력으로 바꿨습니다. "남은 n" 숫자, 진행 막대, 아래 요약 문장과 범례 줄, "이번 달" 버튼은 없앴습니다.

## 날짜 칸

학습 흐름과 같이 계획 하나를 한 번만 셉니다 (`planDays`).

- 다 끝낸 날: 청회색으로 꽉 찬 동그라미
- 하다 만 날(오늘 포함 지난날, 또는 미리 끝낸 계획이 있는 앞날): 끝낸 비율만큼 차는 링
- 계획만 잡힌 앞날: 숫자 아래 작은 점
- 계획 없는 날: 흐린 숫자
- 오늘은 숫자를 굵게 하고 아래에 "오늘"을 적습니다.

## 미리보기와 이동

- 날짜를 누르면 화면을 떠나지 않고 오른쪽(좁은 화면은 아래)에 그날 계획 제목과 완료 여부가 보입니다.
- "이동" 버튼이나 이미 선택된 날짜를 한 번 더 누르면 그날의 나의 하루로 갑니다.
- 다른 달의 날짜를 누르면 그 달로 넘어갑니다.

## 색

학습 흐름의 `--flow-*` 변수를 그대로 씁니다 (`src/MonthCalendar.css`). 선택한 날의 배경만 `--month-selected`로 따로 두었고, 밤 테마 값도 있습니다. 요일 이름의 빨강과 파랑은 회색으로 통일했습니다.
