# Dayly 시작 화면 구현 기록

기준: `START_SCREEN_PLAN_20261020.md` 개정 2 및 참고 Soda 프롬프트.

## 구현 선택

CSS 3D로 앞표지·표지 안쪽·뒤표지·책등·종이와 세 단면을 구성했다. 외부 모델, CDN, WebGL 또는 새 라이브러리가 필요하지 않아 처음부터 정적인 플래너를 표시하고 바로 앱에 접근할 수 있다. CSS 방식의 한계로 곡면과 물리 기반 그림자는 표현하지 않는다.

스크롤은 브라우저 기본 동작을 사용한다. 데스크톱은 1.6 화면, 모바일은 1.1 화면의 이동 거리에서 회전 → 표지 열기 → 종이 확대 → 실제 UI 연결을 진행한다. `requestAnimationFrame`은 입력 이벤트가 발생할 때만 예약하며, 프레임별로 React 상태나 상속 CSS 변수를 갱신하지 않는다. 움직이는 속성은 transform과 opacity다. 화면 밖이나 숨겨진 탭에는 연속 렌더링 루프가 없다.

실제 앱을 한 번만 마운트한다. 마지막 교차 전환은 실제 할 일 카드의 위치와 크기를 기준으로 계산한다. 가려진 앱에는 inert와 aria-hidden을 적용하고, 표시가 끝난 시점에 조작을 허용한다. 키보드·화면의 건너뛰기는 플래너 제목으로 포커스를 옮긴다. 중간 스크롤에서도 고정된 건너뛰기 링크를 제공한다.

동작 줄이기 설정에서는 sticky와 스크롤 변형을 제거하고 정적 표지 다음에 앱을 일반 문서 흐름으로 표시한다. 설정의 실행 중 변경도 반영한다. 모바일에서는 포인터 기울기를 끄고 회전각과 이동 거리를 줄인다.

## 진입과 복원

- 새로운 기본 주소 진입은 시작 화면을 표시한다.
- `#planner`는 앱 직접 진입 주소다. 쿼리나 해시가 있는 목적 링크는 시작 화면을 건너뛴다. 인증 콜백의 매개변수는 인증 SDK가 처리한다.
- 현재 브라우저 history 항목에 메뉴·날짜·달력 월·스크롤 위치를 기록해 새로고침과 뒤로 가기를 복원한다. 할 일·계정·작성 중 글은 이 상태에 복제하지 않는다.
- 저장소 접근 실패는 진입을 막지 않는다. “다시 보지 않기” 설정은 추가하지 않았다.

## 화면 정리

스튜디오 색상은 아침 `#F0EFEB`, 밤 `#202329`다. 홈의 큰 시계·명언·스탠드·책 장식·오른쪽 테마 선택기를 제거했다. 시간은 날짜 옆 작은 텍스트로 표시한다. 테마는 기존 상단 버튼과 설정에서 조작한다. 종이 같은 카드 표면을 사용하고 입력 경계와 본문 대비는 유지한다.

## 코드와 검증

| 파일 | 책임 |
| --- | --- |
| `src/WelcomeScreen.tsx` | 진입 레이아웃, 건너뛰기와 앱 단일 마운트 |
| `src/PlannerObject.tsx` | 책의 각 면과 장식용 빈 속지 |
| `src/plannerScroll.ts` | 진행률, 측정, 역재생, 접근성, 관찰자 정리 |
| `src/entryNavigation.ts` | history 항목의 화면·위치 복원 |
| `src/studio.css` | 스튜디오 색상, CSS 3D, 모바일·동작 줄이기 |
| `tests/e2e/welcome.spec.ts` | 기본 주소 진입·스크롤·포커스·복원·작성 유지·320px·WebGL 불가 |

기존 기능 테스트는 목적이 명확한 `/#planner` 주소로 접근한다. 새 시작 화면 테스트는 기본 주소 `/`를 사용한다. 시각 검증용 캡처는 `.local/welcome/`에 저장하며 Git에 포함하지 않는다. 실제 사용자 계정이나 서버 데이터 변경 없이 테스트 API 응답으로 검증한다.

실제 휴대폰 GPU 성능과 Safari/Firefox는 별도 실기기 확인이 필요하다. 배포는 기존 `main` 브랜치의 GitHub Pages 워크플로를 사용한다.

검증 결과: 프로덕션 빌드 성공, 단위·SQL 테스트 72개 통과. 브라우저 검사 68개 중 처음 확인된 모바일 날짜 크기와 인증 복구 후 새로고침 문제를 수정하고 관련 20개를 재검증했다. 최종적으로 68개 검사 항목 모두 통과를 확인했다. 종이 면과 실제 카드의 위치·크기 차이가 10px 미만인 조건, 동작 줄이기 설정의 반복 전환도 포함한다. 기존 앱 번들의 500kB 크기 경고는 남아 있다.
