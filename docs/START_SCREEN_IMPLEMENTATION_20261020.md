# Dayly 시작 화면 구현 기록 — 사용자 피드백 반영

수정일: 2026-10-20. 최초 `START_SCREEN_PLAN_20261020.md`를 구현한 뒤, 사용자의 후속 요청에 따라 아래 동작으로 변경했다. 과거 기획안의 스크롤 역재생과 화면 정리 규칙보다 이 피드백을 우선한다.

## 한 번만 열리는 진입

- 첫 아래 방향 휠·스크롤·터치 스와이프를 시작 신호로 사용한다. 스크롤 양으로 애니메이션 진행률을 제어하지 않는다.
- 데스크톱 약 1.55초, 모바일 약 1.25초 동안 부분 회전 → 표지 펼침 → 종이 확대 → 실제 앱 연결을 자동 진행한다. 도중에 손을 멈추거나 반대로 스크롤해도 되감지 않는다.
- 완료되면 시작 화면 전체를 `hidden` 처리하고 문서의 진입 여백을 제거한다. 앱은 문서 상단에서 계속 사용하며, 위로 스크롤해도 시작 화면으로 돌아가지 않는다.
- 현재 history 항목에 `intro: false`, `entered: true`를 저장한다. 새로고침·뒤로 가기는 메뉴·날짜·위치 복원을 우선한다. 새 기본 주소 방문에는 새 시작 화면을 표시한다.
- 전환 시작 직후 새로고침하더라도 앱으로 바로 들어간다. 인증 SDK가 해시를 지우면서 만드는 새 방문 항목에도 직접 진입 상태를 저장한다.
- 실제 앱은 계속 한 번만 마운트한다. 가려진 동안만 inert·aria-hidden을 사용하고, 완료 시 입력을 활성화한다.

## 타이포그래피와 표지

큰 세리프체 대문자 DAYLY를 중앙에 배치했다. 책을 열 때 글자 5개가 약간의 시차를 두고 위로 사라진다. 화면의 “스크롤해서 펼치기”, “플래너 바로 열기” 안내는 제거했다. 키보드로 Tab을 누를 때만 표시되는 건너뛰기 링크는 남겨 두었으며, 키보드의 스크롤 키로도 즉시 진입할 수 있다.

표지·책등·뒤표지·종이 단면·리본은 CSS 3D로 구성한다. 표지 재질과 이중 그림자, 안쪽 면을 보정했다. 변형을 제어하는 부모 면에 불투명도 애니메이션을 걸지 않고 각 표면에서 처리해, 표지를 펼칠 때 겉면 문자가 반대로 보이는 현상을 방지한다.

React Bits 공식 HoloCard를 표지에 통합했다. 요청한 `preset="bursts"`, `scale={1.85}`를 사용하며, scale은 화면에서 책을 확대하는 값이 아니라 홀로그램 무늬의 크기다. 피카츄 대신 자체 제작한 `planner-cover.svg`를 사용한다. 기존 책의 회전과 충돌하지 않도록 `surfaceOnly` 모드를 추가했다.

홀로그램은 WebGL2로 렌더링하고, 캔버스는 2–3배 픽셀 밀도로 그린다. 기본 이미지가 SVG이므로 WebGL2·셰이더가 동작하지 않아도 일반 표지를 표시하고 플래너에 진입할 수 있다. 원본 출처와 전체 라이선스는 `src/HoloCard.tsx` 및 `docs/licenses/ReactBits-LICENSE.md`에 보존했다.

## 복원한 플래너 요소

홈의 시계와 날짜, 아침·밤 선택기를 복원했다. 넓은 화면에서는 할 일 오른쪽에, 작은 화면에서는 위쪽의 간결한 카드에 표시한다. 명언·응원 문구와 스탠드 장식은 넣지 않았다.

메뉴 이동에는 기존 `page-enter` 기반의 짧은 전환을 사용한다. 낮·밤 변경은 브라우저가 지원하면 View Transition으로 부드럽게 교차 전환하며, 지원하지 않으면 즉시 적용한다. 작성 중인 글과 인증 상태를 재생성하지 않는다.

## 접근성·성능

- 동작 줄이기 설정에서는 첫 입력으로 즉시 앱을 연다. 키보드 건너뛰기도 즉시 완료하고 플래너 제목으로 포커스를 전달한다.
- CSS·WAAPI의 transform·opacity로 진입을 처리하며, 프레임마다 React 상태를 갱신하지 않는다.
- HoloCard는 `idle={false}`를 사용하고 포인터가 멈춰 안정화되면 그리기를 중단한다. 탭이 숨겨지거나 시작 화면을 떠나도 새 프레임을 예약하지 않는다.
- 모바일 주소 표시줄에 따른 높이 변경은 실행 중 애니메이션의 도착 위치를 갱신하며, 애니메이션을 처음부터 재생하거나 강제 완료하지 않는다.
- 외부 모델·CDN·별도 패키지 의존성은 추가하지 않았다. 표지와 앱은 각기 별도 모델 로딩에 종속되지 않는다.

## 검증

프로덕션 빌드와 브라우저에서 자동 진입, 역방향 스크롤 후 재등장 방지, 타이포그래피 연출, 새로고침·뒤로 가기, 로그인·입력 유지, 시계·테마, 메뉴 이동, 320px·390px, 동작 줄이기를 검증한다. 별도 검사로 WebGL 불가 대체 표지와 진입 후 실제 WebGL 그리기 호출 중단을 확인한다. 화면 캡처는 `.local/`에 저장하며 Git에 포함하지 않는다.

실제 휴대폰 GPU와 Safari/Firefox는 별도 실기기 확인이 필요하다. 기존 앱 번들의 500kB 경고는 남아 있다. 배포는 기존 main 브랜치 GitHub Pages 워크플로를 사용한다.
