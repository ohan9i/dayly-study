# 학습 흐름 개편 (2026-10-26)

학습 흐름 화면을 그림 두 개로 줄였습니다. 다른 화면과 겹치던 숫자 요약 띠, "선택한 날" 진행 막대, 고정 응원 문구는 뺐습니다.

## 한 해의 흐름

- 선택한 날짜가 들어 있는 주까지 53주(일요일 시작)를 하루 한 칸으로 보여 줍니다.
- 칸의 진하기는 그날의 계획 달성률입니다. 세부 항목 수와 상관없이 계획 하나를 한 번만 셉니다 (`planDays`, `flowLevel`).
  - 0단계: 계획이 없거나 끝낸 계획이 없음
  - 1단계: 25% 미만, 2단계: 25% 이상, 3단계: 50% 이상, 4단계: 모두 끝냄
- 칸을 누르면 그날의 나의 하루로 이동합니다. 오늘과 선택한 날짜 이후의 칸은 비워 둡니다.
- 좁은 화면에서는 가로로 스크롤되고, 처음에는 가장 최근 주가 보입니다.

## 주 / 월 차트

- 주: 선택한 날짜까지 7일, 월: 선택한 날짜가 속한 달의 모든 날.
- 막대는 계획 수(연한색)와 끝낸 계획 수(진한색)입니다. 점선은 지난주 또는 지난달의 하루 평균 완료 수입니다.

## 색

플래너 표지의 청회색(`--planner-cover`)에서 가져온 5단계를 `src/StudyFlow.css`의 `--flow-*` 변수로 정의했습니다. 밤 테마는 같은 계열을 어둡게 바꾼 값을 씁니다. 화면 문구에 중간점(·)은 쓰지 않습니다.
