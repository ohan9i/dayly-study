# 2026-10-21 사용자 요청에 따른 입력 흐름 복원

같은 날 작성한 디자인 감사안 이후의 사용자 요청을 우선 적용한다.

## 밀기 동작

계획 제목 줄과 각 세부 항목 줄에 같은 동작을 제공한다. 오른쪽은 추가, 왼쪽은 삭제다. 거의 끝까지 밀고 놓으면 끝 위치로 이동하며, 완전히 열린 뒤 1초 후 실행한다. 손을 놓지 않고 끝 위치에서 1초 기다려도 실행된다. 짧은 밀기는 복귀한다.

추가는 곧바로 입력 가능한 창을 연다. 세부 항목 추가는 선택한 항목 바로 다음에 빈 입력칸을 만들고 초점을 둔다. 새 내용은 저장 버튼으로 저장한다. 삭제는 별도 확인 창 없이 실행한다. 계획은 기존 휴지통으로 옮기며, 세부 항목 삭제는 남은 항목의 ID와 완료 상태를 보존하고 기존 기록과 첨부를 삭제하지 않는다.

대기 중 취소 버튼, Escape, 다른 곳 선택, 원위치로 되밀기, 날짜 또는 공간 이동, 화면 이탈로 실행을 취소할 수 있다. 세로 스크롤과 완료 체크는 밀기 작업에서 분리한다. 키보드로 행에 초점을 두고 오른쪽 또는 왼쪽 화살표를 누르면 같은 1초 대기를 사용한다. 계획 추가와 삭제는 쓰기 권한, 세부 항목 추가와 삭제는 내용 편집 권한을 확인한다.

행 이동은 transform, 대기 표시는 scaleX로 처리한다. 포인터 이동 때마다 React 상태를 갱신하지 않는다. 대기 타이머와 애니메이션은 취소 및 컴포넌트 해제 시 정리한다.

## 입력과 표시

편집 권한이 있는 계획은 상세 창을 여는 즉시 제목, 날짜, 세부 항목을 수정할 수 있다. 별도의 편집 진입 버튼을 제거했다. 처음 수행 기록을 열면 바로 입력창을 표시한다. 기존 초안 보존과 업로드 재시도 보호는 유지한다.

계획 추가 작업과 설정의 휴지통, 변경 이력, 백업을 접는 아코디언에서 일반 영역으로 복원했다. 테마 선택기의 색과 스프링 움직임도 이전 구현으로 복원했다. 펼쳐지는 플래너 속지는 날짜, 글자, 가짜 목록이 없는 백지다. 속지 내용을 보여 주던 애니메이션도 제거해 표지 열기와 본 화면 전환만 이어지게 했다. 앱 화면의 중간점 구분 문자는 모두 제거했다.

## 검증

브라우저에서 999ms 시점의 미실행과 1000ms 이후 한 번만 실행되는 동작, 좌우 밀기, 끝에서 유지, 복귀, 취소, 날짜와 공간 이동, 실제 터치, 실패 후 재시도, 기록 보존과 복구를 검사한다. 기존 편집, 파일 저장, 복제 및 모바일 화면 회귀 검사와 단위 검사를 함께 실행한다.
