# 플래너 구름 배경

이 문서는 이전 구현 기록이다. 현재 배경은 [LiquidChrome 구현](PLANNER_STYLE_AND_CHROME_20261020.md)으로 교체했으며 구름 영상과 포스터는 제거했다.

- 사용자 첨부 `prisma-hero` 예제의 배경 영상에서 구름 영역만 사용한다. 예제의 문구·내비게이션·버튼은 추가하지 않는다.
- 원본: https://d8j0ntlcm91z4.cloudfront.net/user_38xzZboKViGWJOttwIXH07lWA1P/hf_20260405_170732_8a9ccda6-5cff-4628-b164-059c500a2b41.mp4
- 사람·절벽·전봇대가 보이지 않는 684×480 영역을 추렸다. 소리를 제거하고 24fps H.264로 압축했으며 마지막 0.75초를 앞부분에 이어 부드럽게 반복한다. 결과 영상은 약 443KB, 정지 이미지는 약 18KB다.
- 첫 책 애니메이션이 끝난 뒤 메인 플래너에서만 배경 영상을 불러온다. 다른 메뉴로 이동하면 제거하고, 숨겨진 탭에서는 재생을 멈춘다.
- 시스템의 애니메이션 줄이기 또는 데이터 절약 설정에서는 정지 이미지를 사용한다. 영상 오류나 자동 재생 제한이 있어도 정지 이미지를 남긴다.
- 배경은 클릭·키보드·화면 낭독 대상으로 만들지 않는다. 계획 카드의 불투명한 읽기 면과 기존 글자·기능을 유지하고, 배경 명암은 기존 낮·밤 테마에 맞춘다.
- 기존 React/CSS와 브라우저 영상 재생만 사용하며 앱 의존성을 추가하지 않는다. 가공 도구와 원본은 `.local/`에 두고 배포하지 않는다.

검증: `npm run build`, Playwright의 planner-clouds, welcome, atmosphere, check-stability 시나리오.
