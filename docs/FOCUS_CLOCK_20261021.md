# 타이머와 스톱워치

메인 화면 시계 아래에 같은 폭·배경색·테두리·모서리를 사용하는 시간 측정 카드를 배치했다. 기존 밤낮 전환과 같은 SquishSwitch로 타이머와 스톱워치를 전환한다. 모바일에서는 기존처럼 할 일 목록 다음에 시계가 나오며 새 카드는 시계 바로 아래에 놓인다.

## 사용 방법

- 타이머는 기본 25분이며 시간·분·초 입력칸에서 직접 설정한다. 시간은 0~99, 분과 초는 0~59의 정수이며 0초 설정에서는 시작할 수 없다.
- 시작·일시정지·계속·초기화를 지원한다. 진행 중에는 설정값을 잠그고, 일시정지하거나 초기화하면 다시 편집할 수 있다. 일시정지 중 설정을 바꾸면 새 설정 시간부터 시작한다.
- 타이머가 끝나면 0에서 멈추고 카드 안에 완료 문구를 표시한다. 다시 시작하면 마지막 설정 시간으로 시작한다. 초기화 역시 마지막 설정 시간으로 돌아간다.
- 스톱워치는 0부터 시간을 기록하며 시작·일시정지·계속·초기화를 지원한다.
- 두 기능은 독립적으로 진행된다. 모드 전환이나 앱 메뉴 이동은 측정을 중단하지 않으며, 다른 모드의 타이머가 끝나도 완료 안내를 표시한다.
- 로그인 없이 사용할 수 있다. 측정 상태는 해당 탭의 sessionStorage에 보관해 같은 탭의 새로고침 후에도 복원한다. 다른 기기로 동기화하지 않는다.

## 시간 계산과 성능

타이머는 종료 시각, 스톱워치는 시작 시각과 누적 시간을 저장한다. 화면 갱신 횟수를 시간으로 세지 않으므로 숨겨진 탭에서 실행이 늦어져도 돌아왔을 때 실제 시각으로 다시 계산한다.

진행 중이고 화면에 보일 때만 250ms 간격으로 표시값을 확인하고, 표시할 초가 바뀔 때 해당 카드만 갱신한다. 숨겨진 탭이나 다른 메뉴에서는 표시 갱신 루프를 멈추고 타이머 종료를 위한 한 번의 예약만 유지한다. 브라우저가 탭 실행을 중단한 동안에는 안내 표시가 늦을 수 있지만, 돌아오면 종료 여부를 즉시 확인한다.

스크린리더에는 매초 값을 반복 낭독하지 않고, 시작·일시정지·완료 상태만 안내한다. 입력과 버튼, 전환 스위치는 키보드로 사용할 수 있으며 동작 줄이기 설정은 기존 스위치에서 지원한다.

## 구현 파일과 검증

- `src/FocusClock.tsx`: 독립적인 측정 상태, 입력, 저장과 시간 계산.
- `src/FocusClock.css`: 시계와 같은 카드 디자인 및 반응형 배치.
- `src/App.tsx`: 시계와 새 카드를 묶는 오른쪽 열.
- `tests/e2e/focus-clock.spec.ts`: 사용자 시간 입력, 시간 건너뛰기 후 계산, 일시정지·계속·초기화·완료, 모드 전환·메뉴 이동·새로고침, 숨겨진 탭 복귀, 입력 검증, 키보드, 320·390·1000·1440px의 낮·밤 배치.
