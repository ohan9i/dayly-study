# 2026-10-21 디자인 개선 구현

기준 문서: [디자인·인터랙션 개선안](DESIGN_AUDIT_20261021.md).

## 보존 범위

첫 진입의 책·표지·진입 스크롤 연출, LiquidChrome 렌더링과 파라미터, 낮·밤 테마 데이터, 배경 덮개와 그라데이션을 유지했다. `studio.css`와 배경에서 참조하는 기존 변수 값은 변경하지 않았다. 새 `planner-ui.css`와 `--ui-*` 토큰은 UI 요소에서만 사용한다.

## 초안의 유지 범위

- 글은 같은 탭의 새로고침까지 복원한다. 탭을 닫거나 브라우저가 sessionStorage를 삭제하면 복원되지 않는다. 저장소가 차단되면 화면 이동 중 메모리 보존만 제공한다.
- 선택 파일은 현재 페이지의 메모리에서 유지한다. 새로고침·탭 종료 후에는 파일을 다시 선택해야 한다. 작성 영역에 이 범위를 표시하고, 저장하지 않은 작업이 있으면 페이지 이탈을 경고한다.
- 계획 편집은 닫기 시 확인 정책을 사용한다. 사용자가 `변경 버리기`를 선택하면 미저장 편집과 파일 선택은 복원하지 않는다.
- 기록 저장 중 접거나 다른 날짜를 보더라도 진행 상태와 요청 ID는 남는다. 공간 접근 권한이 바뀌면 기존 서버 검사가 작업을 거부하고 초안과 오류를 보존한다.
- 계획 휴지통의 복원 정책과 세부 항목 편집, 대기 첨부 삭제 정책은 구분한다. 저장된 기록·첨부의 영구 삭제나 서버 권한 정책을 추가하지 않았다.

## 검증

`npm run build`, 기존 단위·SQL 권한 검사와 Playwright 브라우저 검사를 사용한다. `design-audit.spec.ts`는 초안 복원, 부분 첨부 실패의 재시도, 닫기 보호, 통계 날짜, 검색 초점·문장, 320·390·420·768·1440px의 낮·밤 배치와 키보드 동작을 검사한다. 기존 밀기·긴 누름 기대값은 일반 작업 메뉴·일반 버튼 흐름으로 갱신했다.

결과: 빌드 성공, 단위·SQL 권한 검사 72개 통과. 브라우저 시나리오 104종은 분할 실행과 재검증으로 모두 통과했다. 병렬 렌더링에서 지연되거나 중단된 항목은 기본 단일 브라우저로 다시 검사했다. 마지막 모바일 배치·초안 복원·테마 조작도 별도로 확인했다. 동작 시간이 짧아진 체크·스위치는 특정 프레임 개수를 강제하지 않고 상태 변화와 최종 상태를 확인한다.

브라우저의 API 대역을 사용하는 검증이며 실제 사용자의 기록을 수정하지 않는다. 실제 휴대폰 하드웨어와 실제 계정의 업로드·공간 이동은 자동 테스트 결과와 구분한다. 첫 화면·배경 보존은 보호 대상 소스의 변경 여부와 기존 브라우저 테스트로 확인하며, 움직이는 배경을 임의 시점 픽셀 일치로 판정하지 않는다.
